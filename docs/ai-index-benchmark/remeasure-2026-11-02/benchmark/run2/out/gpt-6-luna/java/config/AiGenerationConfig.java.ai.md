> Configures per-model AI generation, including source-text limits, sampling, llama.cpp runtime options, remote-provider routing, and output stop conditions.

#### Purpose
- Carries mutable generation settings from Maven configuration to AI providers.
- Supplies defaults for inference, input trimming, provider selection, and llama.cpp execution.

#### Type
- `public class AiGenerationConfig` — class; annotated `@ToString`, with JSpecify `@Nullable` fields; no `equals`/`hashCode` generation.
- Includes nullable `AiCalibration` timing calibration.

#### Input
- No-argument constructor; settings are supplied through setters.
- Configuration values include model path, token and character limits, sampling options, runtime/device settings, provider/API details, stop strings, and calibration.

#### Output
- Getters expose configured values; mutable fields retain setter updates.
- List getters return unmodifiable views; `toString()` is generated by Lombok.

#### Core logic
- Initializes fields from public defaults; `DEFAULT_THREADS` is capped at four and available processor count.
- Represents optional settings with sentinel values, empty strings, or nullable values (notably chat-template thinking and model path).
- Resets nullable string/list inputs to defaults or empty lists in selected setters.
- Stores generation and llama.cpp controls without validating their ranges.
- Captures provider routing (`provider`, `remoteModel`, `baseUrl`, `apiKeyEnv`) and generation controls, including DRY sampling, reasoning budget, and stop strings.
