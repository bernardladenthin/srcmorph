> Configures model routing, prompt limits, sampling, reasoning, hardware, caching, and stopping behavior for an AI generation run.

#### Purpose
- `AiGenerationConfig` carries mutable per-model generation settings from Maven configuration to AI providers.
- Supplies defaults for inference, input trimming, provider selection, and machine calibration.

#### Type
- `AiGenerationConfig` — public class; `@ToString`; no superclass or implemented interfaces.
- Public constants define defaults for context/output limits, sampling, hardware, caching, provider settings, reasoning, and DRY repetition control.

#### Input
- No-argument constructor; all settings are populated through setters.
- Accepts model path, token and character limits, sampling and repetition parameters, provider/API settings, hardware controls, caching options, stop strings, and optional `AiCalibration`.
- List setters accept `null` to reset to empty; several string setters normalize `null` to their defaults.

#### Output
- Getters expose configured values; list getters return unmodifiable views.
- Mutates configuration fields through setters; `toString` is generated by Lombok.
- No file, network, or inference operations.

#### Core logic
- Initializes fields from constants, including a thread default capped at four and the machine’s available processor count.
- Stores inference limits and sampling controls, including temperature, top-p/top-k, min-p, top-n-sigma, and repetition penalties.
- Stores prompt-trimming controls; `charsPerToken` and `maxInputChars` are configuration inputs for provider-side trimming.
- Supports nullable chat-template thinking mode: `null` represents unset.
- Stores llama.cpp execution options for KV reuse, GPU/CPU layer placement, batch sizes, devices, cache types, Flash Attention, and tensor-read mode.
- Supports per-model provider routing and OpenAI-compatible endpoint, model ID, and API-key environment-variable name.
- Stores reasoning effort/budget, DRY parameters and sequence breakers, stop strings, and optional calibration.
- Does not validate numeric ranges or apply provider settings itself.
