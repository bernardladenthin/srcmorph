#### Overview
This project combines billing and order operations with service deployment, worker management, and traffic monitoring. Perl tools summarize access logs and identify slow requests, while shell scripts handle releases, health checks, worker lifecycle checks, and nightly Oracle payment exports. XML assets support configuration, validation, and presentation for reminders, shipments, and account statements.

- other/shell — Automates service release deployment and health monitoring, queue-worker lifecycle checks, and nightly Oracle payment exports for operational reporting.
