> Configures model routing, prompt limits, sampling, hardware, caching, and reasoning options for AI-generated source summaries.

#### Purpose
- Carries per-model generation settings between Maven configuration and AI provider implementations.
- Supplies defaults and mutable JavaBean accessors for inference, prompt trimming, provider routing, and calibration.

#### Type
- `public class AiGenerationConfig` — class; no declared supertypes; annotated `@ToString`, `@SuppressWarnings`.
- Public constants define defaults for context/output limits, sampling, threads, prompt trimming, caching, hardware, provider/API settings, reasoning, and DRY sampling.
- Uses nullable model path, chat-template thinking mode, and calibration; list settings hold DRY sequence breakers and stop strings.

#### Input
- No-argument constructor; settings supplied through setters.
- Configuration values include GGUF model path, inference and sampling parameters, prompt limits, cache/GPU/device settings, provider and remote API options, reasoning and DRY options, stop strings, sequence breakers, and optional `AiCalibration`.
- `DEFAULT_THREADS` reads `Runtime.getRuntime().availableProcessors()`.

#### Output
- Accessors expose configured values; setters mutate instance fields.
- List getters return unmodifiable views; list setters replace the backing list or reset it to empty when passed `null`.
- `toString()` is generated by Lombok over instance fields.

#### Core logic
- Initializes configuration fields from public defaults, including a nullable, unset chat-template thinking mode and per-machine calibration.
- Provides direct getter/setter access for generation and provider configuration; does not perform inference or validate numeric ranges.
- Normalizes `null` to defaults in setters for lazy mode, cache types, devices, provider, remote model, base URL, and API-key environment name.
- Leaves model path, thinking mode, and calibration nullable; reasoning effort is assigned directly.
- Uses `-1`, empty strings, and zero values as documented “leave default,” disabled, or unset sentinels.
- Defines prompt-cache and SWA defaults for prefix reuse; exposes model routing between run-level providers and per-model provider overrides.
