> Carries model, sampling, prompt-trimming, provider, and runtime settings for an AI generation step between Maven configuration and AI providers.

#### Purpose
- `AiGenerationConfig` stores mutable per-model generation settings, initialized from defaults and populated through JavaBean setters.
- Covers prompt limits, sampling and repetition controls, llama.cpp runtime options, remote-provider routing, stop strings, and optional machine calibration.

#### Type
- `public class AiGenerationConfig` — class; no explicit superclass or interfaces; `@ToString`, `@SuppressWarnings`.
- No `equals` or `hashCode` generation; instances are mutable and identity-managed.

#### Input
- No-argument constructor; no constructor parameters.
- Setters accept model path, context/output limits, sampling parameters, threading, prompt caching, GPU/device and KV-cache settings, provider and remote API configuration, reasoning and DRY controls, stop strings, calibration, and other generation options.
- `modelPath`, `chatTemplateEnableThinking`, and `calibration` are nullable.
- `setLazyMode`, `setCacheTypeK`, `setCacheTypeV`, `setDevices`, `setProvider`, `setRemoteModel`, `setBaseUrl`, and `setApiKeyEnv` normalize null to their defaults; list setters normalize null to empty lists.

#### Output
- Stores configured values in mutable instance fields; getters expose configuration values.
- List getters return unmodifiable views of the stored DRY sequence breakers and stop strings.
- `toString()` is generated by Lombok over instance fields.
- No I/O or generation is performed by this configuration object.

#### Core logic
- Initializes configuration fields from constants, including a context size of 32768, output limit of 128, temperature `0.15f`, and thread count capped at four or available processors.
- Provides JavaBean accessors for inference limits, sampling, prompt trimming, provider routing, model runtime, and retry-independent generation options.
- Preserves sentinel values such as `-1` for “leave upstream default” and `null` for an unset chat-template thinking mode.
- `charsPerToken` defaults to 4; its documentation specifies zero disables automatic input-limit calculation in favor of `maxInputChars`.
- List setters retain the supplied list reference (or create an empty list for null); list getters wrap the current list as unmodifiable.
