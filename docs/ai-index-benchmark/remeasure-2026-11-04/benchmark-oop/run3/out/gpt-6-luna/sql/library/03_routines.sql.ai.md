> Implements library book checkout and return workflows, calculates capped overdue fees, and records loan checkout and return events.

#### Purpose
- Enforces member and copy availability during checkout; updates loan and copy status on return.
- Audits loan events and computes late fees in cents.

#### Type
- PostgreSQL / PL/pgSQL; creates table `loan_audit`, function `fn_checkout_book`, procedure `sp_return_book`, function `fn_late_fee`, trigger function `trg_loan_audit_fn`, and trigger `trg_loan_audit`.

#### Schema
- `loan_audit`
  - `audit_id BIGSERIAL` — primary key; `NOT NULL` (declared `PRIMARY KEY`)
  - `loan_id BIGINT NOT NULL`
  - `action VARCHAR(10) NOT NULL` — CHECK `action IN ('CHECKOUT', 'RETURN')`
  - `changed_at TIMESTAMPTZ NOT NULL DEFAULT now()`
- Index: `loan_audit_pkey` — `loan_audit(audit_id)`, primary-key index (name generated by PostgreSQL).

#### Reads
- `fn_checkout_book`: `member.member_id`, `member.is_blocked`; `book.book_id`, `book.copies_free`.
- `sp_return_book`: `loan.loan_id`, `loan.returned_on`, `loan.book_id`.
- `fn_late_fee`: parameters `p_due_on`, `p_returned_on`; reads `CURRENT_DATE`.
- `trg_loan_audit_fn`: trigger row fields `NEW.loan_id`, `NEW.returned_on`, `OLD.returned_on`; reads `TG_OP`.

#### Writes
- `fn_checkout_book`: updates `book.copies_free`; inserts one row into `loan(book_id, member_id, due_on)` per successful call.
- `sp_return_book`: updates `loan.returned_on`; updates `book.copies_free`.
- `trg_loan_audit_fn`: inserts into `loan_audit(loan_id, action)` when invoked for checkout or a newly returned loan; at most one row per trigger invocation.
- `trg_loan_audit`: fires after `INSERT` or `UPDATE OF returned_on` on `loan`.

#### Relationships
- `loan_audit.loan_id -> loan.loan_id` — audit records refer to loans; no foreign key is declared.
- `loan.book_id -> book.book_id` — used to restore copy availability; no foreign key is declared.
- `loan.member_id -> member.member_id` — checkout records the member; no foreign key is declared.

#### Routine logic
- `fn_checkout_book(p_member_id BIGINT, p_book_id BIGINT, p_days INTEGER DEFAULT 21) RETURNS BIGINT`
  - Raises an exception if the member is blocked or no free copy is available.
  - Decrements `book.copies_free`, inserts a loan due on `CURRENT_DATE + p_days`, returns the new `loan_id`.
- `sp_return_book(p_loan_id BIGINT)`
  - Sets `loan.returned_on` to `CURRENT_DATE` only for an unreturned loan; raises an exception if unknown or already returned.
  - Increments the associated book’s `copies_free`.
- `fn_late_fee(p_due_on DATE, p_returned_on DATE) RETURNS INTEGER`
  - Immutable SQL function; calculates overdue days using `p_returned_on` or `CURRENT_DATE`, floors at zero, charges 50 cents per day, caps at 2000 cents.
- `trg_loan_audit_fn() RETURNS TRIGGER`
  - Inserts `CHECKOUT` audit on loan insertion; inserts `RETURN` audit when `returned_on` changes from NULL to non-NULL; returns `NEW`.

#### Dependencies
- Tables: `member`, `book`, `loan`, `loan_audit`.
- Built-ins: `now()`, `CURRENT_DATE`, `COALESCE`, `GREATEST`, `LEAST`.
