#### Purpose
- Holds all parameters needed for a single AI generation step.
- Bridges Maven configuration and AI provider implementations.

#### Type
- Class `AiGenerationConfig`.

- Extends `Object`.
- Annotated with `@ToString` from Lombok.

- Fields initialized to default constants (e.g., `DEFAULT_CONTEXT_SIZE`).
