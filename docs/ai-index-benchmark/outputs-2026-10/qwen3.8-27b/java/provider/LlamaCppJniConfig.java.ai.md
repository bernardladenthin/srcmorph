> Immutable configuration value object for the llama.cpp JNI AI provider, carrying all sampling, GPU, KV-cache, DRY, and OpenAI-compatible endpoint parameters needed to drive a local or remote LLM inference session.

#### Purpose
- Immutable record-shaped config for the `llama.cpp` JNI provider in the `srcmorph` code-generation pipeline.
- Single source of truth for all 40 inference knobs (sampling, GPU offload, KV cache, DRY, stop strings, OpenAI-compatible endpoint) with defaults sourced from `AiGenerationConfig`.

#### Type
- `public final class LlamaCppJniConfig`
- Annotations: `@ConvertToRecord`, `@ToString`, `@EqualsAndHashCode` (Lombok)
- Contains one nested `public static final class Builder`

#### Input
- `Builder` constructor: `String modelPath` (required, non-null)
- 39 optional builder setters, each defaulting to `AiGenerationConfig.DEFAULT_*`
- `List<String> drySequenceBreakers`, `List<String> stopStrings` (nullable, treated as empty)

#### Output
- `build()` → `LlamaCppJniConfig` (immutable)
- 40 record-style accessor methods returning field values
- `drySequenceBreakers()` and `stopStrings()` return `Collections.unmodifiableList(...)` views

#### Core logic
- Pure data holder; no computation.
- Builder pattern: `builder(modelPath)` is the sole entry point; all other fields pre-set to `AiGenerationConfig.DEFAULT_*`.
- String setters (`lazyMode`, `cacheTypeK`, `cacheTypeV`, `devices`, `provider`, `remoteModel`, `baseUrl`, `apiKeyEnv`, `reasoningEffort`) guard against `null` by restoring the default.
- List setters (`drySequenceBreakers`, `stopStrings`) guard against `null` by substituting `Collections.emptyList()`.
- `chatTemplateEnableThinking` is `@Nullable Boolean` — `null` means "omit the kwarg entirely."
- `equals`/`hashCode`/`toString` generated by Lombok over all 40 fields; float comparison uses `Float.floatToIntBits`.
