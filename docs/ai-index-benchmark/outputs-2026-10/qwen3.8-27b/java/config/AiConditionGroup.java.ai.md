> Wraps a list of child `AiCondition` elements to serve as the body of `<and>`/`<or>` combinators in Maven plugin XML configuration.

#### Purpose
- DTO that holds a collection of `AiCondition` children for use inside `AiCondition` combinator nodes.
- Field named `conditions` so Maven's XML binding produces `<conditions><condition>…</condition></conditions>` (Maven singularizes the field name for the item element).

#### Type
- `public class AiConditionGroup`
- Annotations: `@ToString` (Lombok), `@SuppressWarnings({"NullAway.Init", "initialization.fields.uninitialized"})`

#### Input
- `setConditions(final @Nullable Collection<AiCondition> conditions)` — accepts any `Collection` of `AiCondition`.

#### Output
- `getConditions()` returns `@Nullable List<AiCondition>` (defensive copy stored internally).
- `@ToString` generated by Lombok.

#### Core logic
- Stores a nullable `List<AiCondition>`; setter defensively copies via `new ArrayList<>(conditions)`, nulls pass through as null.
- No business logic beyond storage; exists purely to satisfy Maven's XML collection-binding naming convention.

#### Public API
- `AiConditionGroup()` -> void — no-arg constructor
- `getConditions()` -> `@Nullable List<AiCondition>` — returns child conditions or null
- `setConditions(Collection<AiCondition>)` -> void — sets child conditions (defensive copy)

#### Dependencies
- `java.util.ArrayList`, `java.util.Collection`, `java.util.List`
- `lombok.ToString`
- `org.jspecify.annotations.Nullable`
- `net.ladenthin.srcmorph.config.AiCondition` (referenced type)

#### Exceptions / Errors
- No exceptions thrown. Null input to `setConditions` is accepted and stored as null.

#### Concurrency
- No synchronization; not thread-safe. Mutable field `conditions` is not volatile.
