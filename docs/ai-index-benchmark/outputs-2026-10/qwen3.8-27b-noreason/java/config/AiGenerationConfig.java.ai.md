> Carries all llama.cpp and OpenAI-compatible inference parameters (sampling, KV cache, GPU offload, DRY, provider routing) for a single AI generation step between the Maven plugin and the AI provider.

#### Purpose
- Mutable JavaBean configuration object holding every parameter for one AI generation call (model path, sampling, retry, input trimming, stop strings, provider selection).
- Bridges the Maven plugin configuration layer to `LlamaCppJniAiGenerationProvider` and `openai-compatible` provider implementations.

#### Type
- `public class AiGenerationConfig`
- Annotated `@ToString` (Lombok), `@SuppressWarnings({"NullAway.Init", "initialization.fields.uninitialized"})`
- No extends/implements; managed by identity (no `equals`/`hashCode`).

#### Input
- Constructor: no-arg, applies all `DEFAULT_*` constants.
- 42 instance fields populated via setters by the Maven plugin framework.
- `DEFAULT_THREADS` computed at class-load from `Runtime.getRuntime().availableProcessors()`.
- `AiCalibration` object injected via `setCalibration`.

#### Output
- 42 getter methods returning field values (primitives, `String`, `Boolean`, `List<String>`, `AiCalibration`).
- `getDrySequenceBreakers()` and `getStopStrings()` return `Collections.unmodifiableList` views.
- `toString()` generated by Lombok over all instance fields for build-log diagnostics.

#### Core logic
- Pure data carrier: no computation beyond null-coalescing in a few setters (`setLazyMode`, `setCacheTypeK`, `setCacheTypeV`, `setDevices`, `setProvider`, `setRemoteModel`, `setBaseUrl`, `setApiKeyEnv`, `setDrySequenceBreakers`, `setStopStrings`).
- 42 `DEFAULT_*` constants encode tuned llama.cpp defaults: sampling (temperature 0.15, top-p 0.9, top-k 40, min-p 0.0, top-n-sigma -1.0, repeat-penalty 1.0), KV cache (swa-full, cache-reuse 256, flash-attn off, cache-type-k/v empty), GPU (gpu-layers -1, cpu-moe -1, cpu-ffn -1, main-gpu -1, devices empty), batching (batch-size -1, ubatch-size -1, threads-batch -1), DRY (multiplier 0.0, base 1.75, allowed-length 2, penalty-last-n -1), provider routing (provider empty, remote-model empty, base-url OpenRouter, api-key-env empty), reasoning (effort "low", budget -1), seed -1, context 32768, max-output 128, chars-per-token 4, max-input-chars 120000, warn-on-trim true.
- `DEFAULT_THREADS` capped at `min(4, availableProcessors)` to avoid ggml spinning-barrier slowdown on multi-core machines.
- `DEFAULT_CHAT_TEMPLATE_ENABLE_THINKING` is tri-state `@Nullable Boolean` (null = omit kwarg, true/false = forward verbatim).
- `DEFAULT_SEED` -1 means random-per-request; setting a fixed seed makes re-index diffs reviewable but is not bit-reproducible across thread counts/backends.
