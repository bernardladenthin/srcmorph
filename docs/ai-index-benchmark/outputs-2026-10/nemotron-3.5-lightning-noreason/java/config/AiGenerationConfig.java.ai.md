> Calculates AI generation parameters and defaults for model inference configuration between Maven and AI providers.

#### Purpose
- Mutable configuration object carrying all parameters for a single AI generation step
- Bridges Maven configuration layer to AI provider implementations
- Instances are mutable JavaBeans populated through setters; equals/hashCode intentionally not generated (identity-based)

#### Type
- Class: `public class AiGenerationConfig`
- Annotations: `@ToString` (Lombok), `@SuppressWarnings("NullAway.Init", "initialization.fields.uninitialized")`
- No extends / implements; contains numerous `public static final` default constants

#### Input
- Constructor: `AiGenerationConfig()` with no-op initialization
- Setter methods for all fields accept parameter values
- Default constants serve as initial values for each configuration parameter

#### Output
- Getter methods return current configuration values
- `getDrySequenceBreakers()` and `getStopStrings()` return unmodifiable list views
- `getCalibration()` returns `@Nullable AiCalibration` or null
- `toString()` generated by Lombok over instance fields

#### Core logic
- Holds configuration state for AI generation: model path, sampling parameters, retry policy, input trimming limits, stop strings
- Default constants define sensible values: `DEFAULT_CONTEXT_SIZE=32768`, `DEFAULT_MAX_OUTPUT_TOKENS=128`, `DEFAULT_TEMPERATURE=0.15f`, `DEFAULT_THREADS=Math.min(4, availableProcessors)`
- Parameters cover: context size, output tokens, temperature, threads, chars per token, max input chars, warning on trim, top-p/top-k/min-p/top-n-sigma sampling
- Repetition penalty settings: `repeatPenalty`, `repeatLastN`, `dryMultiplier`, `dryBase`, `dryAllowedLength`, `dryPenaltyLastN`
- Chat template thinking mode: `chatTemplateEnableThinking` tri-state (null/true/false)
- Prompt caching: `cachePrompt`, `swaFull`, `cacheReuse` for cross-request KV prefix reuse
- GPU/CPU layer offloading: `gpuLayers`, `cpuMoeLayers`, `cpuFfnLayers`
- KV cache types: `cacheTypeK`, `cacheTypeV` (Flash Attention dependent)
- Batch settings: `batchSize`, `ubatchSize`, `threadsBatch`
- GPU device: `mainGpu`, `devices`
- AI provider: `provider`, `remoteModel`, `baseUrl`, `apiKeyEnv`
- Reasoning effort: `reasoningEffort`, `reasoningBudgetTokens`
- DRY sampling: `dryMultiplier`, `dryBase`, `dryAllowedLength`, `dryPenaltyLastN`, `drySequenceBreakers`, `stopStrings`
- Seed for RNG: `seed` (-1 = random per request)
