> Models lending library checkouts, returns, late fee calculation, and loan audit trail in PostgreSQL PL/pgSQL.

#### Purpose
- fn_checkout_book lends one free copy of a book to a member and returns the new loan id.
- sp_return_book marks a loan returned and restores the book copy.
- fn_late_fee computes overdue fees in cents capped at 2000.
- trg_loan_audit_fn and trg_loan_audit record CHECKOUT and RETURN actions into loan_audit.

#### Type
PostgreSQL PL/pgSQL functions and procedures plus a row-level trigger.

#### Schema
loan_audit table:
- audit_id BIGINT PRIMARY KEY generated by BIGSERIAL
- loan_id BIGINT NOT NULL
- action VARCHAR(10) NOT NULL CHECK (action IN ('CHECKOUT', 'RETURN'))
- changed_at TIMESTAMPTZ NOT NULL DEFAULT now()

#### Reads
fn_checkout_book reads member.member_id and member.is_blocked.
fn_checkout_book reads book.book_id and book.copies_free.
fn_checkout_book reads loan.book_id, loan.member_id, loan.due_on during insert.
sp_return_book reads loan.loan_id, loan.returned_on, loan.book_id.
fn_late_fee reads input parameters p_due_on and p_returned_on and CURRENT_DATE.
trg_loan_audit_fn reads NEW.loan_id, NEW.returned_on, OLD.returned_on.

#### Writes
fn_checkout_book writes book.copies_free (decrement).
fn_checkout_book writes loan.book_id, loan.member_id, loan.due_on (insert).
sp_return_book writes loan.returned_on (update).
sp_return_book writes book.copies_free (increment).
trg_loan_audit_fn writes loan_audit.loan_id and loan_audit.action (insert).

#### Relationships
loan_audit.loan_id references loan.loan_id (implied by domain, no FK declared in source).
fn_checkout_book references member.member_id.
fn_checkout_book references book.book_id.
fn_checkout_book references loan.book_id, loan.member_id.
sp_return_book references loan.loan_id and loan.book_id.
sp_return_book references book.book_id.
trg_loan_audit_fn references loan.loan_id and loan.returned_on.
trg_loan_audit_fn references loan_audit.loan_id and loan_audit.action.

#### Routine logic
fn_checkout_book parameters: p_member_id BIGINT, p_book_id BIGINT, p_days INTEGER DEFAULT 21.
- Checks member.is_blocked and raises exception if blocked.
- Decrements book.copies_free where copies_free > 0, raises exception if no free copy.
- Inserts into loan with due_on = CURRENT_DATE + p_days and returns loan_id.

sp_return_book parameter: p_loan_id BIGINT.
- Updates loan.returned_on = CURRENT_DATE where returned_on IS NULL and returns book_id.
- Raises exception if loan unknown or already returned.
- Increments book.copies_free for the returned book.

fn_late_fee parameters: p_due_on DATE, p_returned_on DATE.
- Returns LEAST(GREATEST(COALESCE(p_returned_on, CURRENT_DATE) - p_due_on, 0) * 50, 2000) as INTEGER.

trg_loan_audit_fn trigger function.
- On INSERT into loan inserts loan_audit row with action 'CHECKOUT'.
- On UPDATE of loan.returned_on from NULL to non-NULL inserts loan_audit row with action 'RETURN'.
- Returns NEW.

#### Dependencies
member table, book table, loan table, loan_audit table, trg_loan_audit_fn function, trg_loan_audit trigger.
