> Immutable configuration for the llama.cpp JNI provider, holding thirty-seven model and generation parameters with defaults from AiGenerationConfig.

#### Purpose
- Holds all llama.cpp JNI generation settings as an immutable value type.
- Provides a fluent Builder that applies AiGenerationConfig defaults and requires modelPath.

#### Type
- final class LlamaCppJniConfig
- annotations: @ConvertToRecord, @ToString, @EqualsAndHashCode
- nested public static final class Builder

#### Input
- LlamaCppJniConfig.Builder constructor takes modelPath (String, null-checked via Objects.requireNonNull)
- Builder setters accept int, float, boolean, String, List<String>, and nullable Boolean for chatTemplateEnableThinking
- Builder defaults sourced from AiGenerationConfig.DEFAULT_* constants
- LlamaCppJniConfig private constructor consumes a populated Builder

#### Output
- LlamaCppJniConfig.build() returns a new immutable LlamaCppJniConfig
- Thirty-seven record-style accessors return the corresponding fields
- drySequenceBreakers() and stopStrings() return Collections.unmodifiableList views
- equals, hashCode, toString generated by Lombok over all thirty-seven fields

#### Core logic
- Builder initializes all fields to AiGenerationConfig.DEFAULT_* values except modelPath
- Builder.lazyMode, cacheTypeK, cacheTypeV, devices, provider, remoteModel, baseUrl, apiKeyEnv, reasoningEffort convert null to the matching AiGenerationConfig default
- Builder.drySequenceBreakers and stopStrings convert null to Collections.emptyList
- Builder.build() constructs LlamaCppJniConfig by copying every builder field
- LlamaCppJniConfig stores fields as final; no normalization in the constructor
- Accessors expose modelPath, contextSize, maxOutputTokens, temperature, threads, topP, topK, minP, topNSigma, repeatPenalty, chatTemplateEnableThinking, cachePrompt, swaFull, cacheReuse, gpuLayers, seed, cpuMoeLayers, cpuFfnLayers, kvUnifiedPerSlot, lazyMode, repeatLastN, cacheTypeK, cacheTypeV, flashAttn, batchSize, ubatchSize, threadsBatch, mainGpu, devices, provider, remoteModel, baseUrl, apiKeyEnv, reasoningEffort, reasoningBudgetTokens, dryMultiplier, dryBase, dryAllowedLength, dryPenaltyLastN, drySequenceBreakers, stopStrings
