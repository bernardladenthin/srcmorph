> Carries all mutable parameters for a single AI generation step between Maven configuration and AI provider implementations.

#### Purpose
- Holds model path, sampling parameters, retry policy, input trimming limits, and stop strings for one AI generation step.
- Acts as a mutable JavaBean populated by the Maven plugin framework and passed to AI provider implementations.

#### Type
- `public class AiGenerationConfig`
- Not final, not abstract, no extends, no implements.
- Annotated with `@ToString` (Lombok) and `@SuppressWarnings({"NullAway.Init", "initialization.fields.uninitialized"})`.

#### Input
- Constructor: no-arg public constructor with no parameters.
- Setter parameters for each field: `String`, `int`, `float`, `boolean`, `Boolean`, `List<String>`, `AiCalibration`.
- Injected dependency: none.
- Consumed fields: all instance fields are mutable and populated via setters.
- Read resources: none.

#### Output
- Getter return types matching each field type.
- `getDrySequenceBreakers()` and `getStopStrings()` return unmodifiable views of internal lists.
- Mutated fields: every setter mutates its corresponding instance field.
- Side effects: `toString` generated by Lombok over instance fields for build-log diagnostics.
- `equals`/`hashCode` are intentionally not generated; instances are managed by identity.

#### Core logic
- `AiGenerationConfig` stores configuration state only; no computation or algorithmic logic.
- Defaults are applied via `DEFAULT_*` constants at field initialization.
- `setLazyMode`, `setCacheTypeK`, `setCacheTypeV` convert `null` to empty-string default.
- `setDevices`, `setProvider`, `setRemoteModel`, `setBaseUrl`, `setApiKeyEnv` convert `null` to empty-string default.
- `setDrySequenceBreakers` and `setStopStrings` convert `null` to a new empty `ArrayList`.
- List getters return `Collections.unmodifiableList` to prevent external mutation.
