> Carries all sampling, hardware, and provider parameters for a single AI code-generation step between the Maven plugin configuration and llama.cpp / OpenAI-compatible inference providers.

#### Purpose
- Mutable JavaBean configuration object for one AI generation step in the srcmorph Maven plugin.
- Bridges Maven plugin XML configuration to AI provider implementations (llama.cpp JNI, OpenAI-compatible HTTP, mock).

#### Type
- `public class AiGenerationConfig`
- Annotated `@ToString` (Lombok), `@SuppressWarnings({"NullAway.Init", "initialization.fields.uninitialized"})`
- No extends/implements; no generics.

#### Input
- Populated via setters by the Maven plugin framework (JavaBeans convention).
- `DEFAULT_THREADS` reads `Runtime.getRuntime().availableProcessors()` at class-load time.
- `AiCalibration` object injected via `setCalibration`.

#### Output
- Read via getters by AI provider implementations (`LlamaCppJniAiGenerationProvider`, OpenAI-compatible provider, mock).
- `toString()` generated by Lombok for build-log diagnostics.
- `equals`/`hashCode` intentionally NOT generated; identity-based management.

#### Core logic
- Pure data carrier: 42 instance fields, each with a corresponding `public static final` default constant.
- Fields cover: model path, context/output token limits, sampling (temperature, top-p, top-k, min-p, top-n-sigma, repeat penalty, DRY), hardware (threads, GPU layers, CPU MoE/FFN layers, batch sizes, KV cache types, Flash Attention, SWA, cache reuse), provider routing (provider name, remote model, base URL, API key env var), reasoning (effort, budget tokens), stop strings, DRY sequence breakers, and optional `AiCalibration`.
- Several String setters null-guard to their `DEFAULT_*` constant (e.g. `setLazyMode`, `setCacheTypeK`, `setCacheTypeV`, `setDevices`, `setProvider`, `setRemoteModel`, `setBaseUrl`, `setApiKeyEnv`).
- List fields (`drySequenceBreakers`, `stopStrings`) return `Collections.unmodifiableList` views from getters; setters null-guard to `new ArrayList<>()`.
- `chatTemplateEnableThinking` is a tri-state `@Nullable Boolean` (`null` = omit kwarg, `true`/`false` = forward verbatim).
- `maxInputChars` auto-calculated from `contextSize`, `maxOutputTokens`, `charsPerToken`, and safety margin when `charsPerToken > 0`; falls back to `DEFAULT_MAX_INPUT_CHARS` when `charsPerToken == 0`.
