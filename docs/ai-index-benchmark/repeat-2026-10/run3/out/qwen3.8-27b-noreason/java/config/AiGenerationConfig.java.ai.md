> Carries all sampling, model, and provider parameters for a single AI generation step between the Maven plugin configuration and the llama.cpp / OpenAI-compatible AI provider implementations.

#### Purpose
- Mutable JavaBean configuration object for one AI generation step (model path, sampling, retry, trimming, stop strings, provider routing).
- Bridges the Maven plugin configuration layer to `LlamaCppJniAiGenerationProvider` and `openai-compatible` provider implementations.

#### Type
- `public class AiGenerationConfig`
- Annotations: `@ToString` (Lombok), `@SuppressWarnings({"NullAway.Init", "initialization.fields.uninitialized"})`
- No extends/implements; no generics.

#### Input
- Populated via setters by the Maven plugin framework (JavaBean injection).
- `Runtime.getRuntime().availableProcessors()` read at class-load for `DEFAULT_THREADS`.
- `AiCalibration` object injected via `setCalibration`.

#### Output
- All state read by AI provider implementations via getters.
- `toString()` generated by Lombok for build-log diagnostics.
- `equals`/`hashCode` intentionally NOT generated; identity-based.

#### Core logic
- Pure data holder: 42 instance fields, each with a corresponding `DEFAULT_*` constant and getter/setter pair.
- `DEFAULT_THREADS` computed at class init as `Math.min(4, availableProcessors())` to avoid ggml spinning-barrier slowdown on low-core machines.
- `maxInputChars` auto-calculated from `contextSize`, `maxOutputTokens`, `charsPerToken`, and `DEFAULT_SAFETY_MARGIN_CHARS` when `charsPerToken > 0`; falls back to `DEFAULT_MAX_INPUT_CHARS` (120000) when `charsPerToken == 0`.
- `chatTemplateEnableThinking` is tri-state (`null`/`true`/`false`): `null` omits the `enable_thinking` kwarg entirely so the model's chat-template default applies.
- `dryPenaltyLastN` uses `-1` as a srcmorph sentinel meaning "do not send"; the binding rejects negatives, so the provider must guard before forwarding.
- `flashAttn` is a boolean: `true` emits `--flash-attn on`; `false` emits nothing (llama.cpp default is `auto`, not off).
- `cacheTypeV` quantization generally requires `flashAttn = true`.
- `provider` field routes a single model to `llamacpp-jni`, `openai-compatible`, or `mock`, overriding the run-level `generationProvider`.
- `apiKeyEnv` stores only the environment variable *name*, never the key itself; empty means no key sent.
- List fields (`drySequenceBreakers`, `stopStrings`) return `Collections.unmodifiableList` views from getters; setters accept `null` to reset to empty.
- String setters (`lazyMode`, `cacheTypeK`, `cacheTypeV`, `devices`, `provider`, `remoteModel`, `baseUrl`, `apiKeyEnv`) null-coalesce to their `DEFAULT_*` constants.
