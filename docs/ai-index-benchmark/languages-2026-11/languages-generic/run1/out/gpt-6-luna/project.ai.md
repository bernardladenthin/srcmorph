#### Overview
The project’s operational tooling covers access-log reporting, production releases and worker health, and settled-payment exports. XML-based configuration defines the build, scheduling, validation, and presentation of invoice, reminder, shipment, and account-statement workflows.

#### Packages

- other/shell — Automates release rollout, queue-worker health management, and daily settled-payment exports for production operations.
- other/xml — Defines XML-based build, scheduling, validation, and presentation configuration for invoice, reminder, shipment, and account-statement workflows.
