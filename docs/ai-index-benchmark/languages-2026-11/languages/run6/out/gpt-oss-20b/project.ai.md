#### Overview
The core of srcmorph‑modelcard is a toolkit that aggregates web‑server logs, automates release deployment, and supplies XML/XSLT utilities for a billing system. The Perl subpackage focuses on log aggregation, generating per‑host and per‑status summaries, and a CLI for reporting busiest hosts and status‑code tallies. The shell subpackage handles deployment of release tarballs to multiple hosts and runs a queue‑worker service with health checks. The XML subpackage provides build, scheduling, and XML/XSLT utilities that support the billing and logistics workflows.
