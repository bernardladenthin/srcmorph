#### Overview
The srcmorph‑modelcard project is a multi‑language toolkit that ingests web‑server logs, aggregates metrics, and automates deployment and service control. It orchestrates invoicing workflows by combining Perl modules that parse access logs and produce JSON summaries, shell utilities that deploy releases, manage a queue‑worker service, and extract nightly payments from Oracle, and XML components that provide build, configuration, and data‑formatting support for invoicing and reminders. Together, these subsystems enable end‑to‑end processing from log ingestion to invoicing and reminder generation.
